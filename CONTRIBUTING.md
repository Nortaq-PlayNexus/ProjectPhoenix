# Contributing to Project Phoenix

Thank you for your interest in contributing to Project Phoenix!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a feature branch (`git checkout -b feature/amazing-feature`)
4. Make your changes
5. Run the tests (`dotnet test`)
6. Commit your changes (`git commit -m 'Add amazing feature'`)
7. Push to your branch (`git push origin feature/amazing-feature`)
8. Open a Pull Request

## Development Setup

- **Runtime:** .NET 6.0 SDK
- **IDE:** Visual Studio 2022 or Rider (recommended)
- **Build:** `dotnet build Phoenix.sln`
- **Test:** `dotnet test`

## Code Style

- Follow standard C# conventions
- Use regions sparingly
- Keep methods focused and concise
- Document public APIs with XML comments

## Pull Requests

- One feature/fix per PR
- Include a clear description
- Ensure all tests pass
- Request review before merging

## Issues

- Use issue templates when available
- Include reproduction steps for bugs
- Label appropriately
