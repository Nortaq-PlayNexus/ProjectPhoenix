# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within Project Phoenix, please send an email to the maintainers. All security vulnerabilities will be promptly addressed.

**Please do NOT report security vulnerabilities through public GitHub issues.**

## Disclosure Policy

- Acknowledgment within 48 hours
- Status update within 7 days
- Resolution timeline communicated upon assessment

## Security Best Practices

- Never commit secrets, API keys, or credentials
- Use environment variables for sensitive configuration
- Enable HTTPS in production deployments
- Keep dependencies updated

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest | :x:                |
